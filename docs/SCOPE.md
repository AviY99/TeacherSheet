# TeacherSheet V1 — Scope lock

## Included now
1. Capture an exercise page with the phone camera.
2. Upload an image, PDF or DOCX example.
3. Google Document AI OCR/layout extraction for image/PDF sources.
4. OpenAI analysis of exercise structure.
5. Teacher review/edit of detected structure.
6. Structural worksheet draft from the decoded structure.

## Explicitly excluded from V1
- Vocabulary input or vocabulary extraction screens.
- Vocabulary replacement/generation logic.
- Quality validation/checking workflow.
- Answer key.
- Final worksheet/export workflow.
- Templates/history/accounts.

A Word Bank is represented only as a boolean structural feature in this version. The system must not extract or manage its vocabulary yet.
